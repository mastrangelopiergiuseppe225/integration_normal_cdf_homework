Exercise 1 — Riemann and Lebesgue integration

For a bounded function on a finite interval, a Riemann-style sum partitions the domain. A finite-valued Lebesgue-style approximation partitions the range: group points whose function values lie in the same value bin, measure those preimages, then weight each measure by a representative value.

Riemann midpoint:   Σ f(xᵢ*) Δx    |    Range-bin approximation:   Σ cⱼ · measure{x : f(x) ∈ binⱼ}

The range-bin method is a practical simple-function approximation, not automatically a computational shortcut: estimating preimage measures still requires sampling or analyzing the sets. Both approximations converge to the same Lebesgue integral for bounded Riemann-integrable functions when their mesh/refinement is suitable. A range partition alone does not guarantee convergence unless the value-bin width tends to zero and the preimage measures are computed accurately.

Exercise 2 — Numerical standard normal CDF

The standard normal CDF is Φ(x)=∫−∞x φ(t)dt, where φ(t)=e−t²/2/√(2π). Its antiderivative is not expressible using elementary functions. This follows from the differential-algebraic criterion behind Liouville’s theorem: an elementary antiderivative of e−t² would require a rational function R satisfying R′−2tR=1; no rational R can satisfy that identity. The error function is introduced precisely to name this non-elementary integral.

erf(z) = (2/√π) ∫₀ᶻ e−u²du    and    Φ(x) = ½[1 + erf(x/√2)]

This is an exact analytical representation in terms of a special function. Numerical computation remains necessary because erf and Φ generally have no elementary closed form and software must return finite-precision values. Algorithms use stable approximations, rational approximants, continued fractions, or convergent series in different regions.

Efficiency and accuracy

Composite Simpson quadrature over a finite interval has global error O(h⁴) for smooth integrands, with O(N) evaluations. The erf power series converges for all finite arguments, but for large |x| alternating/large terms can cause cancellation and many terms; symmetry Φ(−x)=1−Φ(x) and tail-specific methods improve stability. A practical library switches algorithms by input region. The interactive implementation reports timing and discrepancy against known checkpoints, while the series plot shows truncation convergence at the chosen x.

Method used here: erf power series for the interactive series estimate, composite Simpson integration for a numerical cross-check, and symmetry for negative inputs. This transparent teaching implementation is not intended to replace a production statistical library in extreme tails.
